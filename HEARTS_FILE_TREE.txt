## 🔄 Data Flow

```
User Action (Wrong Answer)
    ↓
QuizScreen
    ↓
HeartsNotifier.loseHeart()
    ↓
HeartState.loseHeart()
    ↓
Save to Hive (userBox)
    ↓
Notify listeners
    ↓
UI updates (HeartsDisplay)
    ↓
Play animation (HeartLostAnimation)
    ↓
[If 0 hearts] Navigate to HeartsRefillScreen
```

## 🧩 Feature Integration Points

### Quiz Module
- QuizScreen imports hearts widgets
- Checks hearts before quiz start
- Deducts hearts on wrong answers
- Shows animations and dialogs

### Routing Module
- AppRouter adds hearts refill route
- Supports returnPath query param
- Deep linking support

### Storage Module
- HiveStorage userBox stores hearts state
- Persists across app restarts
- JSON serialization via Freezed

### Theme Module
- Uses AppColors for consistency
- Hearts: AppColors.error
- Accents: AppColors.primary

## 🔮 Extension Points

### Easy to Add
- Different heart counts (5 → 6)
- Different refill times (30m → 20m)
- New refill methods
- Server synchronization

### Hooks Available
- `onHeartLost` - Custom actions on loss
- `onHeartRefilled` - Custom actions on refill
- `onOutOfHearts` - Custom blocking behavior
- Timer callbacks - Analytics events
