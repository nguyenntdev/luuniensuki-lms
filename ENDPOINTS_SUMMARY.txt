1. GET /api/v1/classrooms/{classroom_id}/assignments
   📋 List all quest assignments for a classroom
   ✅ Returns completion statistics
   ✅ Shows total students, completed, in progress, assigned
   ✅ Calculates completion rate percentage

2. POST /api/v1/classrooms/{classroom_id}/assignments
   ➕ Create a new quest assignment
   ✅ Assign to entire classroom OR individual student
   ✅ Set custom due date, points, and notes
   ✅ Auto-creates progress entries for students
   ✅ Validates quest is active and not already assigned

3. PUT /api/v1/classrooms/{classroom_id}/assignments/{assignment_id}
   ✏️  Update an existing assignment
   ✅ Modify due date, points override, or notes
   ✅ Changes apply to all students in assignment

4. DELETE /api/v1/classrooms/{classroom_id}/assignments/{assignment_id}
   🗑️  Delete an assignment
   ✅ Cascades to all student progress entries
   ✅ Permanent deletion

5. GET /api/v1/assignments/mine
   📚 Get all assigned quests for current student
   ✅ View across all classrooms or filter by classroom
   ✅ Shows due dates, status, and overdue flags
   ✅ Includes teacher notes and custom points

6. POST /api/v1/assignments/{assignment_id}/submit
   ✅ Submit an assignment as complete
   ✅ Validates quest is actually completed first
   ✅ Updates status: assigned → in_progress → completed
   ✅ Records completion timestamp
