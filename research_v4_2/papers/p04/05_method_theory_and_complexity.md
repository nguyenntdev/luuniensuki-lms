# Method Theory and Complexity — P04

## 1. Mathematical Formalism
Let the curriculum structure be defined as a directed acyclic graph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$ with $|\mathcal{V}| = d$ competencies.
In any curriculum presentation $k$, observed interactions are generated by:
$$X^{(k)} = S T^{(k)} + E^{(k)}$$
where $S \in \mathbb{R}^{n \times d}$ are intrinsic unobserved student mastery variables, $T^{(k)} = (I - A^{(k)})^{-1}$ is the cumulative prerequisite progression operator, and $E^{(k)}$ is zero-mean observation noise.

## 2. Invariant Optimization Objective
The objective is to minimize structural risk across all curriculum shifts:
$$\min_w \mathbb{E}_{(X, y) \sim \mathcal{D}_{all}} \left[ \ell(y, \sigma(\Phi(X, \mathcal{G}) w)) \right] + \lambda \|w\|_2^2$$
where the feature operator is:
$$\Phi(X, \mathcal{G}) = X (I - A^{(k)})$$

## 3. Asymptotic Computational Complexity
- Feature Inversion / Topological Projection: $O(d^3)$ one-time initialization per curriculum configuration (or $O(d + |\mathcal{E}|)$ via topological back-substitution).
- Inference: $O(n \cdot d^2)$ matrix-vector multiplication.
- Training: standard convex logistic regression with Newton-CG / L-BFGS in $O(n \cdot d)$ per iteration.
- Total memory: $O(n \cdot d + d^2)$, fully budget-compliant.
