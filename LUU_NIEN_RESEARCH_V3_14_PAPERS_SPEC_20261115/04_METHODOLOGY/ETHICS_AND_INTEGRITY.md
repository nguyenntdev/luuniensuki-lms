# Data ethics / school pilot / claims gate

**Treat GitHub documentation about IRB approval, consent, schools and survey as internal assertions until source records are verified.** A Markdown protocol is not an approval letter, raw sample, or guardian consent certificate.

1. Human subject participation (especially minors): use an institutionally reviewed, lawful protocol, age-appropriate assent/guardian permissions and a real withdrawal process before collecting records.
2. Dataset adapters: no student names, phone, IPs, school-specific individual attributes or child identifiers in Git, model checkpoints, LLM requests, PR comments or public log files.
3. External datasets: follow terms per file and redistributability; avoid leaking media rights through generated figure assets.
4. Human annotations: preserve real annotator identities privately, assign pseudonymous IDs to scoring code, log adjudication and disagreement; never create synthetic 'experts'.
5. Observational prediction != causal action effectiveness (P06, P13). User-experience gains require genuine evaluation (P08, P09, P14); simulation not substitutable.
6. Scientific false-positive protection: no cherry picking, no deleting unfavorable runs, no run-to-run code mutation behind same config, no backdating preregistrations.
7. Claims on Hue-specific historical sources need primary citations with stable archival page/claim IDs; cannot infer historical truth from Wikidata alone.
8. Institutional or collaborator endorsements need verifiable permission and proof; author affiliations, real school access, approval status verified before submission.
9. Do not allow research agents to send email, solicit minors, interact with live school accounts or modify production without explicit human authorization and established consent.
10. Ethics and source verification can remain BLOCKED; do not mark all research complete while a required human validation is outstanding.
