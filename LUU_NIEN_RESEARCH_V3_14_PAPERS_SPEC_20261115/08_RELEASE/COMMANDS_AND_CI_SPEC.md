## CI matrix
- `source-and-license`: metadata and legal correctness (never dump private sources).
- `contracts`: valid/invalid schema and gold isolation.
- `baseline`: published baseline pinning and equal-budget assertions.
- `methods`: unit, metamorphic, property tests for all 14 modules.
- `smoke`: one tiny example (explicitly synthetic smoke, never primary evidence).
- `full-external`: manually approved artifact-access job, no PII in logs.
- `reporting`: table/figure regenerated byte-for-byte from frozen manifests.
- `release`: provenance, no claims without evidence, coauthor signoff docs.

Avoid writing full external dataset files to GitHub Actions artifacts unless redistribution is explicitly permitted. Artifact integrity (SHA) must be verifiable even if private bytes are held separately.
