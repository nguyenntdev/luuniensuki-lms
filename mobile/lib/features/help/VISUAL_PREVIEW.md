## 🎨 Color Coding

### Header
- Background: Transparent
- Text: White (#FFFFFF)
- Back button: Glass container

### FAQ Section
- Container: Glass (10% white)
- Icon background: Gold gradient (#E8B44C → #D49B38)
- Icon: White help icon
- Items: Glass cards with white text
- Arrow: White chevron (down/up)

### Support Section
- Container: Glass (10% white)
- Icon background: Imperial red gradient (#C41E3A → #A81730)
- Icon: White support agent icon
- Cards: Glass with white text
- Email: White 70% opacity

### Resources Section
- Container: Glass (10% white)
- Icon background: Orange gradient (#FF6B35 → #FF8C42)
- Icon: White book icon
- Cards: Glass with white text

### Social Media Section
- Container: Glass (10% white)
- Icon background: Multi-gradient (Gold → Red)
- Icons: Glass containers (16px radius)
- Labels: White 90% opacity

## 🎭 Interaction States

### FAQ Item - Collapsed
```
┌────────────────────────────────────┐
│ Question text here?              ▼ │
└────────────────────────────────────┘
```

### FAQ Item - Expanded
```
┌────────────────────────────────────┐
│ Question text here?              ▲ │
├────────────────────────────────────┤
│                                    │
│ Answer text appears here with     │
│ detailed explanation. Can span    │
│ multiple lines with proper        │
│ formatting and bullets:           │
│                                    │
│ • Point one                       │
│ • Point two                       │
│ • Point three                     │
│                                    │
└────────────────────────────────────┘
```

### Button - Normal
```
┌────────────────────────────────────┐
│ 📧  Button Title               ►   │
│     Subtitle text                  │
└────────────────────────────────────┘
```

### Button - Pressed
```
┌────────────────────────────────────┐
│ 📧  Button Title               ►   │ ← Slight scale down
│     Subtitle text                  │ ← Ripple effect
└────────────────────────────────────┘
```
