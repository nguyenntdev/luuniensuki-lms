## 🎯 Key Concepts

### Goal Levels
All documents reference these 4 levels:
- **Casual** (Thoải mái): 5 XP/day
- **Regular** (Thường xuyên): 10 XP/day
- **Serious** (Nghiêm túc): 20 XP/day
- **Intense** (Cao thủ): 30 XP/day

See: [README](DAILY_GOALS_README.md#goal-levels) | [Visual Guide](DAILY_GOALS_VISUAL_GUIDE.md#color-scheme-by-goal-level)

### XP Tracking
How the system tracks daily progress:
- Listens to user's totalXp changes
- Automatically adds gained XP to daily goal
- Resets at midnight (preserves goal level)

See: [Implementation](DAILY_GOALS_IMPLEMENTATION.md#xp-tracking) | [README](DAILY_GOALS_README.md#how-it-works)

### Storage
Uses HiveStorage with key `'daily_goal'`

See: [Implementation](DAILY_GOALS_IMPLEMENTATION.md#storage-layer) | [Quick Reference](DAILY_GOALS_QUICK_REFERENCE.md#storage-keys)
